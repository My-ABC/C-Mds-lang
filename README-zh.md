# C Mds Lang

[中文文档](README-zh.md) | [English Documentation](README.md)

这是一个C语言实现一个新的编程语言 <br>
在Windows上编译 <br>
```cmd
./build.bat
```
在Linux上编译 <br>
```shell
make release
```
想要编译 Debug 版本 <br>
Windows:
```cmd
./build.bat -d
```
Linux:
```shell
make debug
```
要清除：
Windows:
```cmd
./build.bat clean
```
Linux:
```shell
make clean
```

# C Mds Lang

[中文文档](README-zh.md) | [English Documentation](README.md)

This is a new programming language implemented in C language
Compile on Windows
```cmd
./build.bat
```
Compile on Linux
```shell
make release
```
Want to compile the Debug version
Windows:
```cmd
./build.bat -d
```
Linux:
```shell
make debug
```
To be cleared:
Windows:
```cmd
./build.bat clean
```
Linux:
```shell
make clean
```
